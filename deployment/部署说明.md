# ChainScope 子目录部署版（2026-10-22）

本包修正页面资源、研究数据和导航链接，使同一份静态网站支持域名根目录及任意子文件夹。界面仍为 0.3.22，研究快照未改变。

## 你当前服务器的操作

1. 保持 emberscrolls.top 原网站根目录 /www/wwwroot/emberscrolls.top，不需要增加子域名或改 DNS。
2. 解压本包，把 dist/ 里面的 index.html、另外三份 HTML、assets/ 和 data/ 上传覆盖到：
   /www/wwwroot/emberscrolls.top/ChainScope-0.3.22/dist/
3. 打开 https://emberscrolls.top/ChainScope-0.3.22/dist/ 。地址末尾保留 /；也可直接访问该目录的 index.html。
4. 若此前已把整个站点根目录改为项目 dist，请先恢复为原主站目录 /www/wwwroot/emberscrolls.top。
5. 浏览器强制刷新，进入 AI 产业链、公司和总结，测试顶部三个导航及底部流程链接。

也可以把 dist/ 里的内容放进网站根目录下的 ChainScope/ 文件夹，这时地址为 https://emberscrolls.top/ChainScope/ 。避免多套一层 dist；这只是两种放置方式，不需要同时部署。

主站首页文件保持原样。无需 Node/Python/API Key，不需要反向代理或全站 SPA 回退。按通常静态站点方式启用 index.html，并允许读取该目录文件。如果 Nginx 对某些子目录另有拦截、alias 或重写规则，仍需按服务器实际配置核对。

## 运行及边界

前端构建：在 frontend/ 中运行 npm ci、npm run build。Vite base 为 ./，数据与站内导航同样使用相对路径，页面状态仍由查询参数保存。所有四个 HTML 在同一级目录。

“分析 / AI 智能总结”仍展示已发布快照，不会在线调用模型或实时更新数据。原有研究验证和缺失证据边界保持不变；本次验证范围见构建校验.json。尚未替用户登录服务器或上传本修正版，公网 URL 需部署后复验。
