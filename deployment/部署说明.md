# ChainScope 0.3.22 腾讯云部署包

构建日期：2026-10-22（北京时间）。本包为已经构建完成的静态网站，不需要在服务器安装 Node.js、Python、数据库或配置 AI API Key。

## 上传什么

**只上传 `dist/` 里面的文件和子目录到网站根目录。不要把 ZIP 本身当网页文件上传，也不要多套一层 dist。**

网站目录应当长这样：

```text
网站根目录/
├── index.html
├── agent_architecture.html
├── cost_performance.html
├── prod_loop.html
├── assets/
│   ├── main-*.js
│   └── main-*.css
└── data/
    └── snapshot.json
```

例如网站根目录是 `/var/www/chainscope`，上传后应存在 `/var/www/chainscope/index.html`。页面使用 `/assets/` 与 `/data/` 绝对路径，当前包适合独立域名根目录或服务器 IP 根目录；不要部署到 `/chainscope/` 等子路径。

包内 `nginx/`、校验文件、构建记录与本说明是运维材料，不属于网站目录。未打包源码、`.git`、`node_modules`、`.env`、研究原始响应或凭证；同时省略未被当前页面使用的旧快照和重复开发说明文件。

## 方案一：腾讯云服务器 / 轻量服务器，使用宝塔或类似面板

1. 在面板中建立一个纯静态网站，绑定你的域名或服务器 IP，并记下网站根目录。
2. 在面板文件管理中上传部署包并解压。将 `dist/` 内全部内容复制到该网站根目录，保持 `assets/`、`data/` 层级。
3. 默认文档设为 `index.html`。无需 PHP、反向代理、Node 项目或 5173 端口。
4. 站点监听 HTTP 80；在腾讯云实例对应的安全组 / 防火墙和系统防火墙中按需放行该端口。域名应解析到实例公网 IP。若配置 HTTPS，则在面板中为实际域名配置证书与 443 监听，并放行 443。
5. 通过 `http://你的域名/` 或 `http://服务器公网IP/` 打开。配置证书后使用 HTTPS。
6. `nginx/chainscope.conf` 是独立站点示例。宝塔已有 `server` 块时，只按实际情况合并缓存与 `location` 规则，不要将整个配置再粘到既有 `server` 内部。面板 Nginx 的 `mime.types` 路径可能不同，以实际安装为准。

## 方案二：腾讯云服务器，已有 Nginx

以下假设包已解压到当前目录，且使用新的 `/var/www/chainscope` 目录。已有网站时先保留原站点和配置，选择自己的发布目录。

```sh
sudo mkdir -p /var/www/chainscope
sudo cp -a dist/. /var/www/chainscope/
```

将 `nginx/chainscope.conf` 中的：

- `server_name chainscope.example.com;` 改为你的实际域名或服务器公网 IP。
- `root /var/www/chainscope;` 改为实际网站目录。
- `include /etc/nginx/mime.types;` 改为当前 Nginx 的 MIME 文件路径（如果不同）。

将修改后的配置放入该 Nginx 的 `http` 块实际包含的站点目录。常见安装使用 `/etc/nginx/conf.d/`；目录位置依具体环境而定。确保请求的域名匹配此站点，且 Nginx 工作进程有文件读取和目录遍历权限。

先校验，再应用：

```sh
sudo nginx -t
sudo nginx -s reload
```

本机没有安装 Nginx，因此随包示例尚未经过 Nginx 实机语法与环境校验；以目标服务器 `nginx -t` 结果为准。示例仅配置 HTTP，域名证书及 HTTPS 监听由服务器或面板配置。

本项目使用四个实际 `.html` 页面，页面状态由查询参数保存，不需要把所有 404 都重写到 `index.html`。尤其不要将缺失的 `/data/snapshot.json` 返回为首页。

## 方案三：腾讯云 COS 静态网站

1. 在 COS 中选择专用于该网站的存储桶，将 `dist/` 内的内容上传到桶根目录，确保对象键是 `index.html`、`assets/...`、`data/snapshot.json`，而不是 `dist/index.html`。
2. 按当前控制台指引配置匿名访问网站所需的对象读取权限，开启静态网站，索引文档为 `index.html`。此包没有专门的 404 页面，不需要将错误文档强制设为首页。
3. 绑定并配置自定义域名、域名解析及所需的 HTTPS。腾讯云当前文档说明：2024-01-01 后创建的存储桶，默认域名（含静态网站域名）不再支持直接预览对象，应使用自定义域名；不要把默认桶地址当作一定可用的演示网址。
4. 如果使用 CDN，HTML 和 `data/snapshot.json` 不设长缓存，更新时刷新这些对象；文件名带指纹的 `assets/` 可长缓存。上传时确保 HTML / JS / CSS / JSON 的 Content-Type 正确，且没有强制附件下载的 Content-Disposition。
5. 不要只把 ZIP 上传为一个 COS 对象：它不会自动变成完整网页目录，需要先解压再上传文件。

腾讯云官方设置说明（核对日期 2026-10-22）：[COS 设置静态网站](https://cloud.tencent.cn/document/product/436/32670)。该文档包含默认域名访问限制、索引文档及自定义域名说明。

## 部署后检查

1. 打开 `/`，能看到“研究”首页，勾选 AI 并开始分析。
2. 进入产业环节，选择英维克，点击“AI智能总结”，可以看到已有研究。
3. 打开 `/agent_architecture.html`、`/cost_performance.html`、`/prod_loop.html`，均可正常显示。
4. 直接访问 `/data/snapshot.json`，应返回 JSON，而不是 HTML、403、404 或下载错误；研究版本应为 `2026-10-22.p2.deep.b1h.p1.c`。
5. 刷新带公司查询参数的地址，公司与总结状态应保留。

如果首页空白，先检查网页资源路径，特别是有没有把整个 dist 文件夹嵌进网站根目录。若显示“暂时无法打开研究数据”，检查 `data/snapshot.json` 是否上传、读取权限及缓存。若域名打开旧站点，检查 DNS、Nginx 的域名匹配及 CDN 缓存。

## 文件校验

在解压后的本包目录，可用 Linux 自带工具核对：

```sh
sha256sum -c SHA256SUMS
```

macOS 可使用 `shasum -a 256 -c SHA256SUMS`。校验用于确认文件与本次打包版本一致。
