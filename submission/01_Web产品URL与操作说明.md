## 2. 产品定位

面向希望理解 AI 产业链的个人投资者，将产业结构、公司主营业务、证据、概念可信度、中外比较及事件路径放在同一个研究界面。核心价值是让用户看清“关联来自什么证据、哪些数字可比较、哪些内容仍未知”。

这是基于已发布研究快照的交互产品原型。当前有 27 家公司，其中 17 家状态为 reviewed、10 家为 candidate；reviewed 不代表所有公司均完成同等深度研究。当前仅 AI 可进入分析，其余概念为 Demo。

## 3. 建议评审主链路

1. 打开研究页面，勾选 **AI**，点击 **开始分析**。
2. 约 3 秒步骤演示结束后，查看产业结构，选择一个产业环节。
3. 在环节弹层中选择公司，例如英维克。先查看基础信息、主营业务、财务指标与报告期。
4. 点击 **AI智能总结**，约 3 秒后展开已有研究；查看归属证据、概念可信度、中外可比边界及事件路径。
5. 展开来源，查看可公开访问的链接及受限来源说明；通过 A–E 说明理解证据等级。
6. 切换公司，检查总结恢复为收起状态；浏览器返回和刷新可用于检查状态恢复。
7. 打开 **全概念市值榜**；未完成研究的榜单公司应显示覆盖限制，不能伪装为完整研究详情。

## 4. 演示前必须说明的边界

- 两处约 3 秒进度属于本地交互演示，展示已有研究，不会触发新的 AI 或金融 API 请求。
- 财务数据、榜单和产业结构来自快照，不是实时行情；以页面标注的报告期与日期为准。
- AI 专项收入未披露或未核实时保留空值；母类别或集团收入不能直接当成 AI 收入。
- A–E 是特定概念下的证据等级，不是信用评级、买卖建议或收益承诺。
- 中外比较受期间、币种、业务结构和会计口径约束；事件包含事实、推断与情景，不能全算作已验证的财务传导。

## 5. 重新启动本地产品

在项目 `chainscope/frontend` 目录执行：

```sh
npm ci
npm run dev -- --host 127.0.0.1 --port 5173 --strictPort
```

如需检查生产包：

```sh
npm run build
npm run preview -- --host 127.0.0.1 --port 4173 --strictPort
```

生产预览入口为 `http://127.0.0.1:4173/`，以实际启动的端口为准。运行和环境说明见 [源代码与 README](02_源代码与README.md)。
