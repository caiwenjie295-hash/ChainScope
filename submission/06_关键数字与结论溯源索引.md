## 如何核对

1. 打开 [产品](https://emberscrolls.top/ChainScope-0.3.22/dist/) 的公司研究，查看指标、概念证据、对照或传导节点的来源。
2. 在 [完整索引 JSON](验证记录/关键数字与结论溯源索引.json) 中搜索公司 ID、指标 ID 或来源 ID。
3. 对照 sources 的 title、locator、url；可公开的链接需回到披露原文核对。派生指标同时保留 scope，现金流减资本开支是分析代理，不是公司披露的统一自由现金流。
4. 事件的 fact / inference / scenario 按原标签解释；情景节点可能没有直接来源，不能视为已经实现的合同或财务影响。
