# 生产闭环说明（原型口径）

> 状态：Finance 2026-10-22 冻结口径｜维护：算法  
> **本仓库交付的是 AI 产品原型**：真实/可核验研究数据 + 闸门 + 慢路径互动演示。  
> **本轮不实现**生产调度、计费、多租户、真用户 Key 调用。

---

## 1. 生产闭环（说明用）

| 步 | 名称 | 做什么 |
|---|---|---|
| 1 | 数据入 | 扶摇 / 公开披露 / feeds 定时拉取 |
| 2 | 批跑 | 按可分析主题**日更增量** DAG + 闸门（禁假 A、禁假 pair 等） |
| 3 | 发布 | `export` 已验证 `snapshot` → 前台**只读**最新包 → **秒开** |
| 4 | 互动 | 用户「开始分析 / 追问」带 Key **加急/加跑** → 发布**新一轮**包，不挡当前摘要 |
| 5 | 事件 | 重大题材可**主题补跑**（增量，非全市场重跑） |

原则：点公司出 C **不等于**全量重跑；慢路径按钮才触发编排。

---

## 2. 本原型如何映射

| 生产步 | 原型里对应什么 |
|---|---|
| 已发布包（步 3） | 静态 `frontend/public/data/snapshot.json`（当前例：`2026-10-22.p2.deep.b1h.p1`） |
| 秒开（步 3） | 选公司 → 立刻展开 C 区四硬（读包，不现算） |
| 加跑/追问（步 4） | 概念层「开始分析」、C 底「追问/深挖」：约 3 秒本地思考态后仍吐**已有** snapshot（演示请求感；**未**调真 Key） |
| 日更/定时（步 1–2） | **未接**；上线时把同一条 `export_p2_joinable` 挂到盘后任务即可 |

---

## 3. 明确不做（本轮）

- 真 cron / 队列 / 多租户计费  
- 点公司触发全量 DAG  
- 慢路径按钮灌**未闸门**的在线假结果  

上线接线时：批跑与按钮加跑共用同一套 registry + 闸门 + export 真源（`frontend/public/data/snapshot.json`）。
