# 0.3.22 用户确认流程

日期：2026-10-22。本文件记录当前用户确认要求；与旧 UX_FREEZE_v1.md 冲突时，以本次用户要求为准。

## 主流程

选择 AI → 点击“开始分析” → 约 3 秒类思考流程 → 出现产业结构图 → 选择环节与公司 → C 区直接显示公司基本信息 → 点击“AI智能总结” → 约 3 秒类思考流程 → 展示已有总结与分析。

- 两处都保留约 3 秒的类思考流程。这是用户最后追加的要求，覆盖此前讨论的“秒出”。
- 选公司立即显示名称、代码、区域/上市市场、主营业务、关键财务指标及报告期。
- 总结展开前不显示归属、概念可信度、中外对比、传导和补充信息等研究正文。
- 点击“AI智能总结”后显示已有研究内容；不新增真实 Agent 调用或编造新分析。
- 末尾没有“深挖/追问”。切换公司后回到基本信息状态，需再次点击“AI智能总结”。

## 页面与入口

- “投资研究”导航改为“研究”。
- 主标题：“产业链跨市场与公司研究ChainScope”；删除旧“先看有对齐期与可追溯披露的主线……”小字。
- 首块名称：“概念板块”。仅 AI 可分析；白酒、智能驾驶、医药等其他概念置灰并注明“Demo，暂无分析”。
- 环节内只显示“公司”，删除此处市值榜与概念权重。
- 单独设置“全概念市值榜”入口，清楚标明所选概念、覆盖条数、日期和计量口径。
- 研究流程大标题改“流程与证据”。
- 成本与验证大标题改“Deepseek Flash API调用成本核算”。
- 以上两个信息页的文字与卡片背景提高对比度。

## 评级与文案

- A–E 概念可信度旁设问号按钮；点击弹窗说明各级标准。
- A 至 E 采用红—白—蓝过渡，字母和释义同时保留，浅色等级也要清晰可读。
- 不改变现有 A–E 研究标准，不将证据级别当作收益、信用或买卖评级。
- 移除“所以呢”措辞。
- 对客来源、提示和正文避免裸露接口参数、访问枚举、内部数据交接备注和指导开发者的句子。

## 数据边界

本次是界面与展示适配修改。已有 snapshot、财务数字、研究等级、引用、研究版本均应保持不变。数据未披露或未核验时保留明确说明。区域只能根据现有数据表达，不补造公司所在地。
