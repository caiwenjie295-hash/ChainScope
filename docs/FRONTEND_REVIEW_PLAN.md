# 投资研究终端体验评审：0.2.0-mvp.2

目标是判断个人投资者能否用较少阅读完成探索，不在本版扩大研究算法范围。

1. 首屏能否在约10秒内看懂研究主题、核心驱动与重点公司？研究时间与报告期是否明确？
2. 能否在两次点击内，从经营表或图谱打开英维克，看到四项指标、一句话判断和业务证据入口？
3. 能否区分集团收入、AI专项收入缺失和未核验候选？
4. 能否看懂英维克／Vertiv的比较理由、半年期间与币种边界？
5. 能否打开判断背后的原始披露，理解哪些证据仅在本地可用？
6. 能否沿真实事件看到传导条件，并区分事实、推断和情景？
7. 市场、搜索、分支过滤后，选中状态与列表是否一致？无结果时能否恢复？
8. 窄屏、键盘、减少动效设置是否仍可使用？

反馈优先记录：操作卡住的位置、理解错误的信息、希望默认看到或收起的信息。先修正这些问题，再决定增加数据、指标或研究算法。

开发分工：用户明确指定 `gpt-6-luna` + `max` 编写前端；主代理整理研究数据、执行验证与保留Git版本。研究模型继续为 `deepseek-flash`。

规范来源：项目要求第3、5、6节，以及 [Vercel React Best Practices](https://github.com/vercel-labs/agent-skills/tree/main/skills/react-best-practices) 和 [Web Interface Guidelines](https://github.com/vercel-labs/web-interface-guidelines)。
