# ChainScope P2 拍板（Finance）

> 日期：2026-10-21（Asia/Hong_Kong）｜依据：用户对 A/B/主题/动态喂数的反馈  
> 公网 URL / 演示视频仍后置。

## 0. 方向判断

**同意切到「AI 概念板」为大前提。** 理由：分类与成分更规范、披露/资讯更密，比手搓「液冷+光模块」切片更像可持续产品；Agent 编排通用，主题换为概念板 taxonomy + 再跑几轮即可。P1 闸门（A–E / export / 可比 / 事件 / impact）保留复用。

不推翻：白/深蓝/深红、A→B→C、红=相关/绿=替代、C 只读已验证、不编造数字。

## 1. A 区交互（重做入口）

| 态 | 内容 |
|---|---|
| **A0 首屏** | 只展示概念/板块分类（来自 snapshot，可多级 chip/树）；**不**默认铺新闻/事件长文 |
| **A1 选概念后** | A 区内出现该概念近段时间的新闻、财报、公告等**链接列表**（标题+日期+来源类型；可点外链或打开摘要） |
| **A2 开始分析** | CTA「开始分析」→ 进入 B（原 S1）；未选概念则 CTA 禁用或提示先选分类 |

约束：链接与分类均由 snapshot/API 喂入，前端不写死概念名、不写死新闻。

## 2. B 区星图

- 语义仍三层（主题→分支→环节），节点数据动态。
- **视觉**：减少横平竖直网格感；允许轻微径向抖动、非均匀角距、有机连线/缓动；仍专业金融风，不科幻炫光。
- impact 红绿规则不变；无核验则 unclear。

## 3. 算法（主题切换）

1. 以 **AI 概念板**（扶摇/iFinD 概念成分 + 层级）重建 `industry_graph` / 公司池；优先可核验分部收入与中外对标的子集深研。
2. 导出 snapshot 增补：
   - `concepts[]`：id/name/parent_id/level/company_count…
   - `concept_feeds[concept_id]`：新闻/财报链接（title/date/url/kind/source_id）
   - 现有 graph/companies/pairs/events/impact 继续，字段向后兼容。
3. 复用 P0/P1 闸门；不编造；窄口径仍可 B/C。
4. 产出：`ALGO_P2_PLAN.md` → 再跑 → 新 snapshot + 字段表 `FRONTEND_FIELDS_P2.md`。

## 4. 前端

- 去掉硬编码主题文案 / 固定四分支文案（能读 snapshot 的一律读数据）。
- A 区按 §1 状态机；B 区灵动布局；动态接收新 snapshot 即可演示换主题。
- 版本预期 **0.3.0**（交互破坏性变更）。

## 5. 分工与顺序

1. @算法 先出 `ALGO_P2_PLAN.md`（概念板数据源、公司池、feeds 契约、工期）→ Finance 过 → 开跑。
2. @UIUX 并行出 A0/A1/A2 + 星图灵动线框（可先 mock 空 concepts），**等字段表后接真数**；禁止写死 AI 数据中心四分支。
3. 两边契约对齐后再联调。

## 6. 成功标准（本轮）

- 打开页：A 只有概念分类，无默认新闻墙。
- 点一概念：出现对应 feeds；「开始分析」进 B。
- B 星图读新 graph，视觉更有机；换 snapshot 不改代码仍可展示（主题名/分支/公司来自数据）。
- 关键数字仍可追溯；无假绿假 A。

## 7. Demo 范围（2026-10-21 补充）

- 仅 **AI 概念板**（种子根及其 `analysis_enabled=true` 子集）可「开始分析」进入 B/C。
- 其它概念/板块：A1 仍展示新闻/财报链接；CTA **置灰**；悬停提示固定文案：`demo对该板块暂无分析`。
- 契约：`concepts[].analysis_enabled`（bool）；前端无字段时默认 false。

## 8. 公司覆盖（纠正「深研 8」）

- 取消全局「只深研 8 家」。
- 每个可分析 AI 子概念：同时导出双榜各 **top10**（见 §9）；深核覆盖双榜并集，不足则 B/C/E，禁假 A。

## 9. 双榜展示（市值 / 概念权重）

- 字段：`concepts[].rank_by_mkt_cap` / `concepts[].rank_by_concept_weight`（`RankBoard`：metric / as_of / items[].rank|value|company_id）。
- 前端页签切换，默认市值；权重无源时空 items + `missing_reason`，禁止假填。
- 详表：`FRONTEND_FIELDS_P2.md`。

## 10. Agent 输出硬指标（候选人附件，必须显眼）

1. 产业链分类口径、层级与公司归属证据  
2. 概念关系 A–E 可信度（有收入→仅表态/无证据）  
3. 中外可比：为何可比 / 哪些不可比  
4. 外部变化→环节→公司业务→财务指标传导路径  

缺一项不算 P2 完成；前端 C 区主位展示，禁止只藏进附录。

## 11. 算法定位（通用框架）

算法主责是 **Agent 编排与开发**：可配置主题 / 模型（含 DeepSeek）/ 数据源；闸门与四硬指标契约稳定。换 API 或概念板应主要改配置与 registry，不重写编排。

## 12. 跨模型复验（用户要求）

Agent 主链路跑通后，算法须用**自有模型**按同一 DAG/闸门/契约完整重跑一轮，对照 DeepSeek 基线，输出稳定性与准确性差异报告（分级漂移、引用断裂、假 A 是否仍被拒、四硬指标是否仍可验）。未过复验不喊 P2 完成。
