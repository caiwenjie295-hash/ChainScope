# 版本与研究快照

界面版本采用 SemVer 预发布标识。`0.2.0-mvp.1` 是图谱导向原型，保留为未验收检查点；`0.2.0-mvp.2` 调整为产业投资研究终端，进入体验评审。后续修订递增预发布序号。正式验收前不标为稳定版。

研究版本独立保留：`2026-10-21.round2`。界面发布记录同时包含界面版本、研究版本、数据包 SHA-256 和 Git 提交。界面更改不伪装成研究更新。

提交按职责分开：研究基线、前端数据适配、前端实现、体验验证与修复。用对应版本的 Git annotated tag 保留可回退节点。

凭证、运行环境、第三方接口原始响应、财报原件和本地测试产物不提交。原件仍在本地 `artifacts/`，JSON 引用保留溯源位置。当前仅建立本地 Git 记录，远程仓库发布独立处理。
