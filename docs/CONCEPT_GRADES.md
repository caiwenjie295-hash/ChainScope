## 0. 这是什么 / 不是什么

| 是 | 不是 |
|---|---|
| **产品证据阶梯**：衡量「该公司 ↔ 该研究概念」关系的**证据强度** | 信用评级（标普等）、证监会/交易所「官方评级」 |
| 投研展示与闸门用的**内部等级** | 数据商「概念纯正度」分数的逐字拷贝 |
| 可与公开**收入确认 / 分部披露 / 主营相关实践**对照 | 临床 CEBM Level、财报 forensic 造假等级 |

**监管层没有「概念股 A–E 国标」**；市面概念板多为数据商自拟。字母 **A–E 名称保留**（Finance 2026-10-21 拍板），含义按下表 + §1 锚点解释。

## 1. 公开口径锚点（对齐用，非照搬公式）

### 1.1 收入确认 → 约束「什么能叫收入证据」

《企业会计准则第 14 号——收入》（财政部）：企业应在履行履约义务、**客户取得相关商品控制权时**确认收入；控制权指能够主导该商品使用并从中获得几乎全部经济利益。

- 官方文本：http://kjs.mof.gov.cn/zt/kjzzss/kuaijizhunzeshishi/201709/t20170907_2694006.htm  
- PDF：https://www.mof.gov.cn/zcsjtsgb/gfxwj/201707/P020200907398079240429.pdf  

**产品对齐**：等级 **A** 的「收入数字」必须来自已确认/已披露的收入类证据；**订单、意向、产品发布不能当 A**（尚未满足「控制权转移下的收入确认」叙事）。

### 1.2 分部 / 分产品披露 → 约束「禁止集团总额冒充概念专项」

- **IFRS 8 Operating Segments**：按管理层审阅的经营分部披露收入等信息。https://www.ifrs.org/content/dam/ifrs/publications/html-standards/english/2026/issued/ifrs8.html  
- **中国证监会年报内容与格式**：要求按行业/产品/地区等披露营收构成；对占营业收入或营业利润较高的分项列示收入等（正式条文以证监会当期准则为准）。  

**产品对齐**：等级 **A** 的 `scope` **不得**为 `consolidated_total`；AI/窄概念不得用集团或过宽母类收入顶替专项口径。

### 1.3 概念成份实践（Wind）→ 对照「强相关」，不等于我们的字母

万得《概念指数编制方案》：以**主营相关性**为核心；主营业务收入与指数主题相关度 **≥30% 定义为强相关**；另有综合评分与代表性选样，**通常不纳入全部样本**。

- 编制方案 PDF：https://www.windindices.com/indicesWebsite/api/preview?direct=1&file=%E4%B8%87%E5%BE%97%E6%A6%82%E5%BF%B5%E6%8C%87%E6%95%B0%E7%BC%96%E5%88%B6%E6%96%B9%E6%A1%88.pdf&lng=03  
- 公开报道转述（含「尚无官方标准」背景）：https://www.jwview.com/jingwei/02-18/617026.shtml  

**产品对齐（对照表，非等价）**：

| Wind 实践（参考） | 本产品 A–E |
|---|---|
| 相关度 ≥30%「强相关」（成份入选启发式） | **不自动等于 A**；A 仍要可核验**专项收入数字** |
| 相关但未达强相关 / 仅主题受益 | 可对应业务存在但收入未单列 → 常为 **B/C** |
| 综合评分+主观确认入选 | 我们另用 claims + `source_ids` + 闸门，不照搬其评分 |

## 2. 定义

| 级 | 含义 | 进入条件 | 禁止 |
|---|---|---|---|
| **A** | 对应概念口径有可核验**收入数值**（优先年报/附注**分行业·分产品·分部**） | `revenue_metric_id` 指向存在、`value` 非 null，且 `scope` **不是** `consolidated_total`；AI 专项不得用集团/母类收入顶替；**不以** IFRS 8「10%」作 A 门槛 | 订单、产品发布、新闻稿金额、集团总收入证明窄概念 A |
| **B** | 有商业业务/销售交付证据，**窄口径收入未知或未披露** | 年报或等价披露支持业务存在；收入 metric 可 null | 把 B 写成「已证明 AI 收入规模」 |
| **C** | 产品发布、订单或项目进展，**尚未核实销售交付** | 进展有 source；保守默认 | 把订单直接评为 B/A |
| **D** | 仅战略表态、合作意向、生态名单，无产品与收入证据 | 本轮可 0 条；预留 | 用新闻稿语气抬到 C 以上 |
| **E** | 本轮证据不足或未核验（含广度候选占位） | 候选默认 E | 将 E 解释为「公司没有该业务」 |

### 证据阶梯（与上表同向）

1. 已审计/法定披露中的**分产品·分部·分行业收入**（→ 才可能 A）  
2. 年报等主源中的**业务/交付**描述，无专项金额（→ B）  
3. 订单、项目、产品发布进展（→ C）  
4. 战略/合作表态（→ D）  
5. 未核验或证据不足（→ E）

## 3. 双轨披露

同一公司可同时有：

1. **宽口径**（如「服务器」「机房温控」）→ 可有 A（若年报单列相关收入）  
2. **窄口径**（如「AI服务器」「AI液冷」）→ 常为 B/C；缺专项收入则 **保持 B/C + 解释**，`ai_specific_revenue=null` + `missing_reason`

前端必须同时可展示窄概念等级与「未披露」，不得因缺数删除窄概念行。C 区 A–E 旁应可展开「本产品定义 / 与外部口径对照」（只读本文，不自创标准）。
