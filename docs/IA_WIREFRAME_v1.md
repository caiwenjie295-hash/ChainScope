## 3. 关键组件地图

### A · 产业入口
- **动机卡**：为何研究（热点事件 + 时间 + 1–2 证据链）
- **主题摘要**：论文式 3–5 句产业结论 +「所以呢」一句
- **主 CTA**：`AI 分析` → S1
- 不放覆盖数字墙、不放开发者注释

### B · 星图与环节
- **ConcentricMap**：L1 主题（最大）→ L2 四分支 → L3 环节（止）
  - 大小 = 体量/重要性；无可比数 → 默认尺寸 +「未披露」
  - 红 = 与主题相关；绿 = 替代/受挤占；深浅 = 强弱
- **SegmentSheet（弹层）**：标题=环节名；搜索框；企业列表（名称/市场/证据等级）；关闭按钮；蒙层不关
- 占位态：浅灰轮廓 +「完成 AI 分析后显示产业结构」

### C · 公司只读区
- **空态**：保留高度，文案「选择环节企业并分析后显示」
- **待分析**：公司名 + ticker + `AI 分析`
- **已填充（只读）**：
  1. 论文式摘要（结论先行）
  2. 证据链（可点来源）
  3. 条形/柱状对比（相对同环节或可比组；缺数用「未披露/未核验」块）
  4. **不**现场调模型；**不**编造财务

## 6. 三处字段钉死（2026-10-21 · 可开工）

### A ·「为何研究」动机卡
| UI 块 | snapshot 字段 | 缺省 |
|---|---|---|
| 问题标题 | `overview.title` | — |
| 研究副题 | `overview.subtitle` | — |
| 驱动事件 | `event.title` + `event.date` | — |
| 动机摘要 | `event.summary` | — |
| 证据链（1–2） | `event.steps` 中 `kind=fact` 优先，取前 2 条的 `text` + `source_ids` → `sources[id]` | 无 fact 则用 steps[0..1] |
| 主题补充要点 | `overview.changes` 前 2 条（title/text/date/source_ids） | 可空 |
| CTA | 本地 UI 状态 `phase`：点「AI 分析」→ S1 | 不调模型 |

### B · 三层节点 + 红绿语义
| 层 | 取数 | 渲染 |
|---|---|---|
| L1 | `graph.nodes` where `type=theme` | 中心最大 |
| L2 | `type=branch`（现：算力与AI服务器 / 高速光通信 / 供配电 / 液冷散热） | 环绕 |
| L3 | `type=segment` | 外环；点击 → 弹层 |
| **不渲染** | `type=company` | 仅进 L3 弹层列表 |

企业列表：`companies.filter(c => c.segment_id === 所选 segment 去前缀后的 id 或节点映射)`；用 `company_id` / `segment_id` 对齐。搜索：`name|ticker`。

红绿映射（**不编造**）：
- 读节点 `impact` 与连边 `direction`：`related|positive|support` → 红；`substitute|crowd|negative|displace` → 绿；深浅用 `confidence` 或固定中档。
- **本轮快照二者全为 `unclear`** → 节点用中性深蓝灰，图例写「相关方向本轮未核验」；有值后再上色。大小：用 `size`；全为 1.0 时统一默认并标「体量未披露」。

### C · 只读摘要字段
| 块 | 字段 |
|---|---|
| 标题行 | `name` · `ticker` · `market` · `exchange` |
| 论文式摘要 | `headline`（结论句）+ `business_summary` |
| 概念判断 | `assessment.concept` / `grade` / `rationale` + `assessment.source_ids` |
| 证据链 | `claims[]`（text/kind/source_ids）+ `SourceRefs` |
| 不确定 | `uncertainties[]` →「未核验/待补证」块 |
| 对比图 | 优先 `pairs` 含该公司者：`summary` + 双方 `revenue_yoy`/`gross_margin`/`net_profit_yoy` 做条形（null →「未披露」）；否则同 `segment_id` 已 `reviewed` 公司前 N |
| 构成条 | `business_composition[]`（share null → 未披露） |
| 闸门 | UI `cAnalyzed`；填充后只读，不调模型 |
