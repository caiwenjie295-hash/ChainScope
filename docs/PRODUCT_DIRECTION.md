# 产业投资研究终端：mvp.2

用户在图谱原型评审后明确调整方向：金融指标、核心判断和投资逻辑是主角，圆形图谱用于解释产业结构。原型检查点为 `bdd5665`；这次调整不重建研究Agent，也不扩大到实时估值或实时研究。

## 用户首先需要回答的问题

- 研究哪个产业，驱动变化是什么？
- 哪些环节可能受益，哪些只是待验证的情景？
- 哪些公司已有真实业务，相关收入能否量化？
- 同期间的增长、毛利率和净利润有什么差异？
- 外部事件通过什么条件影响交付、收入和现金？

## 信息顺序

首页：研究主题与驱动变化 → 四项有明确范围的研究覆盖指标 → 支持探索的产业结构图与重点公司经营表。搜索、市场和分支筛选集中在紧凑工具栏，明确显示当前筛选与总体覆盖数量。

公司详情按需打开：公司身份与概念范围 → 四项核心经营指标和一句话判断 → 主营业务构成与归属证据 → 中外比较 → 事件路径与风险 → 可展开的来源。不得默认铺开大量证据或Agent执行过程。

## 数据边界

- `relevant_revenue_share` 固定对应AI主题专项口径；母类别业务占比放在独立的 `business_composition`，明确包含其他应用。
- `revenue_yoy`、`gross_margin`、`net_profit_yoy` 带报告期间、范围、引用和缺失原因。净利润同比统一说明合并口径，不混入归母或Non-GAAP。
- 百分比采用0–100标度，毛利率变化采用百分点；比率不携带币种。
- 海内外公司保留各自财年；不同期间、币种、业务结构不机械排名。
- 当前研究有8家首批公司及14家候选。按AI专项范围未取得A级收入证据，不等于这些公司没有AI业务。
- 事件案例仍含情景与待验证环节，不能计为完整已验证财务传导路径。

## 体验验收

按“10秒内理解研究主题、关键变化与公司关联；两次点击内看到公司指标和业务证据”的目标设计。该目标需要用户体验评审，不能用开发者自检冒充已完成的定量用户测试。

基础验收涵盖：默认概览、当前/总覆盖数、筛选与搜索、公司详情、证据入口、比较边界、情景标识、键盘与移动端、加载与缺失状态。
