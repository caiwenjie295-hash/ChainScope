# ChainScope 前端体验冻结规格 v1

> 状态：已冻结｜负责人：Finance｜执行：UIUX｜日期：2026-10-21  
> 研究数据：沿用现有 `snapshot.json` / `data/*`（允许空白，前端用状态表达，不编造数字）

## 1. 产品气质

- 面向客户的专业金融研究终端，不是玩具 Demo、不是科幻仪表盘。
- 主色：白底 + 深蓝主色 + 深红强调；少发光、少渐变炫光。
- 页面纵向布局，层次强、信息密度可控；**禁止面向客户的开发者小字注释**（技术口径默认折叠或不展示）。

## 2. 三区阶段流（A → B → C）

| 区 | 作用 | 默认态 |
|---|---|---|
| **A** | 进入产业：为何研究、主题动机、热点与证据 | 首屏主角 |
| **B** | AI 分析后出现三层同心产业图 | A 内点「AI 分析」后出现；未进入前可占位但弱化 |
| **C** | 公司详情：已验证摘要 / 对比 / 图表 | 进入公司并点「AI 分析」后填充；此前保留空位 |

阶段规则：

1. 打开页：A 有内容；B/C 可占位但不抢视线。
2. A 点「AI 分析」→ B 显示星图；C 仍空但保留位置。
3. B 点最外层（第三层）节点 → B 内弹层：搜索 + 企业列表；**点击蒙层不关闭**（需明确关闭按钮）。
4. 选中企业后，在详情入口点「AI 分析」→ C 填充**本轮已验证只读摘要**（不现场调模型）。

## 3. 星图语义（三层为止）

```
L1 中心：AI 数据中心基础设施（最大）
L2：算力与 AI 服务器 / 高速光通信 / 供配电 / 液冷散热
L3：环节（如算力硬件、AI 服务器）——到此为止
```

- 底色白色；中心最大，外周为产业链。
- **红** = 与主题产业相关（正）；**绿** = 替代 / 受挤占（负）；深浅 = 相关强弱。
- **大小** = 重要性或体量；无可比数值时用默认尺寸并标「未披露」。
- 红绿**不是**股价涨跌预测。

## 4. 内容原则

1. **动机先行（A）**：先回答「为什么要研究这个方向」，再给产业主题；补上体验断层。
2. **论文式摘要优先**：产业 / 分支 / 公司各有可扫读结论 + 证据链接；结论先于裸数字。
3. **对比用图**：条形图 / 柱状图优先于卡片数字墙。
4. **空白诚实**：未披露 / 本轮未核验用清晰状态块，不留大片空洞；不假装已算出。
5. **重点突出**：每屏必须有一句「所以呢」式结论，禁止只堆指标。

## 5. 工程约束

- 代码基线：`/workspace/chainscope/frontend`（React + Vite + TypeScript）。
- 数据只读现有快照；不得编造财务或证据；不得在浏览器暴露密钥。
- 遵循既有 Schema / `export_frontend.py` 契约；若缺字段，用现有字段映射或明确「未核验」占位。
- 改版后：`npm run build` 可通过；保留键盘可达与基本响应式。
- 版本：前端 bump 小版本并在 CHANGELOG 记「UX freeze v1」。
