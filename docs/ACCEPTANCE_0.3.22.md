# 0.3.22 验收与数字核对

日期：2026-10-22。前端由用户指定的 gpt-6-luna、max 推理强度实现；主代理进行源码检查、浏览器验收、研究统计核对与打包。基线为用户提供的 chainscope-dev-0.3.21.zip；没有覆盖旧 ChainScope 工作目录。

## 功能验收

- 首页导航“研究”、指定主标题、“概念板块”与仅 AI 可分析的入口已核对。
- “开始分析”与“AI智能总结”都保留 3000 毫秒本地类思考进度；未调用新的研究或金融接口。
- 公司先显示基本信息、主营业务、财务指标与报告期，点击总结前不显示研究正文；点击后展示总结、归属、概念可信度、中外对比、传导及补充信息。
- 切换公司恢复基础信息状态；思考中切换公司不会把上一家公司结果展开到新公司。
- 环节弹层仅公司列表，可搜索代码、展开候选；市值与权重标签已移除。
- 全概念市值榜独立展示 AI 成分股前 10 名；排名连续，注明日期、币种；无研究详情的公司不伪装成详情入口。
- A–E 问号弹窗有五级标准和红—白—蓝分级；检查了 Tab 焦点限制、Esc 关闭、点击外部关闭和焦点恢复。
- 验证了一次浏览器返回收起总结，以及刷新恢复公司、产业结构和总结状态。
- 来源展开已不显示 authenticated_api、fiscal_year=、MCP response、原始响应等标识；毛利率变化单位修正为“个百分点”。
- “流程与证据”“Deepseek Flash API调用成本核算”标题与高对比信息卡已实测。浏览器验收覆盖桌面/侧栏显示；未进行完整实体移动设备兼容性测试。
